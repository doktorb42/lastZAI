# Dawne pliki z katalogu głównego

Ten folder zawiera 88 historycznych plików Pythona przeniesionych tutaj
27 października 2026 r. Nie zostały skasowane ani zmienione. Były przede
wszystkim krótkimi nazwami zgodności lub ręcznymi narzędziami, które nie
powinny zaciemniać normalnego startu PEva.

Aktywna PEva, jej narzędzia oraz testy importują właściwe moduły bezpośrednio
z `oczy/`, `mozg/`, `charakter/`, `emocje/`, `rece/`, `trening/`, `config/`
lub `archive/legacy_runtime/`. Nie uruchamiaj plików z tego katalogu jako
alternatywnego startu aplikacji.
