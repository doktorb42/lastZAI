# Dawne launchery i skrypty pilotów

Ten katalog zawiera uruchomienia techniczne, które nie są częścią normalnej
PEva. Jedynym codziennym startem pozostaje `PEva.cmd` w katalogu głównym.

Znajdują się tu:

- wcześniejsze skróty oddzielnych Oczu, OCR, UI i ręcznego serwera modelu;
- historyczne, ograniczane czasowo skrypty WSL dla pilotów Agency V2–V4.

Skrypty są zachowane jako dowód poprzednich eksperymentów oraz punkt powrotu.
Nie uruchamiają się samoczynnie, nie zmieniają bieżącego modelu i nie są
rekomendowaną drogą do użycia PEva.
