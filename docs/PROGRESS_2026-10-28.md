# PEva: latest verified progress (2026-10-28)

## Private Chat and Group Chat separation

- The upper global `Private Chat` dot is deliberately ignored because Last Z
  also lights it for Group Chat activity.
- A red dot is now a private-message signal only inside the left half of the
  lower `Private Chat` / `Group Chat` chooser. A dot on the lower right Group
  Chat tab, the global strip, a list row, map marker, or event popup cannot
  start a tab switch or OCR.
- When that exact lower-left PM badge appears while PEva is already in the
  global Private Chat view, it refreshes the list through the known sequence
  `Friend Post -> Private Chat` in the upper strip. The lower button is only
  a signal; PEva never clicks it. It cannot use this path from the map.
- The refresh remains limited to a previously confirmed Private Chat list;
  a weak or mistaken Group Chat classification cannot cause a tab tap.
- The detector was checked against the supplied screenshots: the full-screen
  global Private Chat badge is accepted; the Group Chat badge is rejected.

## Conversation title and nickname

- PEva Helper version 11 now retains the centered conversation title below
  the tabs. The previous crop could omit that title and read the first bubble
  sender line instead.
- Private-message sender lines are never a source of conversation identity.
  They are only filtered from message text; the centred title stays primary.
- A separate, inactive-for-now Group Chat sender parser understands both
  `V8 LV.27 name` and `V8 LV.27 gender-icon name`, removing VIP, HQ level,
  gender marker, and optional alliance tag before returning the nickname.
- `V8 LV.27 male-icon DOKTORB` resolves to `DOKTORB`; if OCR reads the male
  icon as a standalone `O`, the same full-prefix rule removes that noise.
- PEva Helper `1.0-peva-helper-private-header` / `versionCode=11` was built
  and installed over the existing app. No app data or granted permissions
  were removed.
