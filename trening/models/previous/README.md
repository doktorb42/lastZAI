# Poprzedni model

To miejsce jest obecnie celowo puste. Nie ma jeszcze wcześniejszego,
zatwierdzonego modelu PEva, który należałoby tu zachować jako punkt powrotu.
Model testowy V4 pozostaje kandydatem — nie wolno oznaczać go jako `previous`
ani `current`, bo nadal zbyt często milczy w normalnej rozmowie.
